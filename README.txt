DOOM // UAC ARCHIVES — Projeto acadêmico

Arquivos:
- index.html: estrutura do site
- style.css: visual responsivo inspirado na estética sci-fi/retro de DOOM
- script.js: menu mobile e janelas informativas dos jogos

Como testar:
1. Extraia a pasta.
2. Abra index.html no navegador.

Como publicar no GitHub Pages:
1. Crie um repositório público chamado doom-portal.
2. Envie index.html, style.css e script.js para a raiz do repositório.
3. Acesse Settings > Pages.
4. Em Build and deployment, selecione Deploy from a branch.
5. Selecione a branch main e a pasta /(root), depois salve.
6. Aguarde a publicação e abra o link exibido pelo GitHub Pages.

Observação:
Projeto acadêmico de fã, sem vínculo oficial com id Software/Bethesda.
Não inclui imagens, logotipos ou arquivos originais protegidos do jogo.
